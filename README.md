# Weblium Trainee QA – Test Assignment

This repository contains the result of a practical test assignment completed for a Trainee QA position.

## About the project

The task was to create a multi-page website in Weblium according to the provided requirements.

The assignment included not only the visual creation of the pages, but also configuring and verifying the functionality of interactive elements, including:

- page navigation;
- buttons and links;
- store categories;
- product pages;
- product options;
- contact forms;
- form fields and validation;
- pop-up windows;
- blog navigation;
- gallery elements.
